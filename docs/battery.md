# Battery Specifications

## Drone Main Battery

**Flywoo Explorer Molicell P30B 18650 4S1P 3000mAh Lionpack Battery**

| Parameter | Value          |
|-----------|----------------|
| Cell      | INR-18650-P30B |
| Capacity  | 4S1P 3000mAh   |
| Voltage   | 14.8V          |
| Discharge performance | 35A (P30B)    | 
| Discharge wire plug   | Flywoo XT30UP |
| Charge wire plug      | JST-XH2.54-4P |
| Weight                | 196.5g        |
